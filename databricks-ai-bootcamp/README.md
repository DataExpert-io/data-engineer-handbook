# Databricks AI Bootcamp

A practical three-day introduction to building AI applications on Databricks.

## Getting started

Before Day 1, create a Databricks Free Edition workspace:

[Sign up for Databricks Free Edition](http://signup.databricks.com/?provider=DB_FREE_TIERutm_source=github&utm_medium=video&utm_campaign=DataExpert)

## Curriculum

| Day | Topic | What you will build |
| --- | --- | --- |
| [Day 1](./day-1-lakebase-simple-application.md) | Lakebase and a simple application | A small application backed by Lakebase. |
| [Day 2](./day-2-context-engineering-vector-databases.md) | Context engineering and vector databases | A retrieval-ready knowledge layer using Databricks Vector Search. |
| [Day 3](./day-3-agent-bricks-end-to-end-ai-applications.md) | Agent Bricks and end-to-end AI applications | An AI application that combines agents, context, and evaluation. |

## Suggested preparation

- Bring a laptop and a Databricks Free Edition account.
- Be comfortable navigating a Databricks workspace and running notebook code.
- Complete the days in order: each day builds concepts useful for the next one.
