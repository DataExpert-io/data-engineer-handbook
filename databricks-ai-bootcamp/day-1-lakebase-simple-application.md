# Day 1: Lakebase and a Simple Application

## Focus

Learn the foundations of Lakebase and use it as the data layer for a simple application.

## What you will cover

- What Lakebase is and where managed Postgres fits in the Databricks platform.
- Creating and connecting to a Lakebase database.
- Designing a small application data model.
- Reading and writing application data.
- Connecting the data layer to a simple application experience.

## Practical outcome

By the end of the day, you will have a simple application backed by Lakebase, with a small schema and a working data-access flow.

## Suggested agenda

1. Introduce Lakebase and application-oriented data storage.
2. Set up a database and application connection.
3. Create a minimal schema and seed it with data.
4. Build a simple create, read, update, and delete workflow.
5. Demo the application and discuss next steps for AI integration.
