# Day 3: Agent Bricks and End-to-End AI Applications

## Focus

Use Agent Bricks to turn the data and context prepared in the first two days into an end-to-end AI application.

## What you will cover

- Agent Bricks capabilities and when to use them.
- Defining an agent task, instructions, tools, and guardrails.
- Connecting an agent to Lakebase data and retrieved context.
- Testing agent behavior with realistic user tasks.
- Evaluating quality and preparing an application for deployment.

## Practical outcome

By the end of the day, you will have an end-to-end AI application design that uses agentic workflows, contextual retrieval, and application data.

## Suggested agenda

1. Define the agent's job, success criteria, and boundaries.
2. Connect the agent to structured data and retrieved knowledge.
3. Implement an end-to-end application workflow.
4. Test and evaluate answers, tool use, and failure cases.
5. Demo the completed application and identify production next steps.
